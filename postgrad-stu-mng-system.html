Project Overview

The Postgraduate Students Management System (PGSMS) is a full-stack web application purpose-built to streamline the academic and administrative workflows for MPhil. and PhD. students. It replaces manual processes with a centralized, automated solution to enhance operational efficiency, improve collaboration, and support academic progress monitoring.

On the technical side, the backend is developed using Spring Boot with REST API architecture, implementing JWT-based authentication and BCrypt password encryption for security. The frontend is built using Angular, delivering a responsive and user-friendly interface. MySQL is used for structured data management, while Gmail SMTP is configured for real-time email notifications. The application is securely deployed with the backend hosted on Render, the frontend on Netlify and database in Neon.

Demonstration

The PGSMS provides secure, scalable, and impactful automation that reduces administrative workload, enhances accountability, and facilitates seamless collaboration among students, supervisors, and examiners.

Key Features

Student Lifecycle Management

From registration to graduation, the system supports every academic milestone

Role-Based User Access

Admins, students, supervisors, and examiners access distinct interfaces and actions based on their roles

Examiner Assignment

Admins assign examiners while the system prevents duplicates or role conflicts automatically

Submission Portal

Students upload half-yearly and final reports; examiners provide structured evaluations and feedback

Enrollment Module

Students enroll online and admins review and approve submissions of students

Email Notification System

Automated emails for submission reminders, approval status, and examiner feedback using customizable templates
