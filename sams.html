Project Overview

This project is a complete IoT-based smart agriculture monitoring system designed to enhance farming decisions by collecting, analyzing, and visualizing real-time environmental and soil data. The list of parameters are,

  • NPK (Nitrogen, Phosphorus, Potassium) values of soil
  • Soil Moisture
  • Rain gauge
  • Sunlight Intensity
  • Temperature
  • Humidity

The system uses multiple hardware devices to capture sensor readings and transmits them via MQTT to Firestore, enabling live monitoring through a mobile app (Flutter) and web app (React + Vite). An independent ML model (YOLOv5) processes aerial images to detect tree count and assess tree health, hosted via Cloud Run.

Hardware Devices

  • Portable Unit- Field workers collect soil data using ESP32, NPK, Moisture, GPS, RTC, SD card, LCD. Stores data offline when Wi-Fi is unavailable.

    • The Portable Device is a mobile unit carried by field workers to measure soil parameters at specific locations. It is equipped with multiple sensor modules including an NPK sensor, Soil Moisture sensor, GPS module (Neo-6M), Real-Time Clock (RTC), SD card module, LCD display, and an ESP32 Dev Kit V1 as the core microcontroller. One of its standout capabilities is the ability to store sensor data offline, using RTC timestamps when a Wi-Fi connection is not available. The device is battery-powered and highly reliable for extended field usage.

  • Fixed Unit- Continuously monitors field data and sends periodic readings to the cloud via MQTT with Wi-Fi and status indicators.

    • The Fixed Device is a stationary monitoring setup designed for continuous deployment in agricultural fields. It continuously monitors environmental parameters and periodically sends sensor data to the cloud using MQTT. To aid in diagnostics and usability, it includes, successful data transmission, and sensor functioning. This setup is particularly suitable for long-term monitoring and acts as a foundation for early warning systems in precision agriculture.

Mobile Application

The mobile application is built using Flutter, integrated with Firebase, Firestore, and MQTT for seamless cloud communication. It provides users with access to real-time and historical data through an intuitive interface. The app features interactive graphs, sensor-based alerts, and the ability to sync data offline, ensuring field workers can operate effectively even without internet access.

Web Application

The web dashboard is developed with a modern stack: React, Vite, and is hosted on Firebase. It offers an interactive dashboard that displays data insights such as geo-located sensor mapping, trend analysis of soil nutrients (NPK), environmental conditions, and detailed device connectivity status.

Access the web application using the link: https://environment-monitoring-system.app/

ML Model

The software system is extended with a separate Machine Learning model based on YOLOv5 for advanced agricultural insights. It is trained to process aerial or field images to deliver two core outputs: Tree Count and Tree Health Classification (Healthy or Unhealthy trees). This model is deployed on Google Cloud Run, and accessible via a RESTful API that accepts image uploads from both the mobile and web interfaces.
